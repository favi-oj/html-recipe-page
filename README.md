# Nigerian Jollof Rice Recipe Page

## Project Description

This project is an HTML-only recipe webpage created
as part of my DigiHub HTML assignment.

The webpage explains how to prepare Nigerian Jollof
Rice, including the ingredients, preparation steps,
important safety notes, and cooking terminology.

## Technologies Used

- HTML5
- Visual Studio Code
- Google Chrome
- W3C Nu HTML Checker
- GitHub

## HTML Features Demonstrated

1. Main heading using h1.
2. Section headings using h2.
3. Introductory paragraph using p.
4. Unordered ingredients list using ul and li.
5. Ordered preparation steps using ol and li.
6. Safety warnings using strong and em.
7. Cooking definitions using dl, dt, and dd.
8. HTML metadata and language declaration.

## Project Files

- recipe.html - Main HTML recipe webpage.
- html-validation-success.png - Validation screenshot.
- README.md - Project documentation.

## HTML Validation

The recipe.html file was tested using the

## How to View the Webpage

1. Download or clone this repository.
